Trigger Watch

Pick your trigger system - its sources and File# sync are configured for you. Each trigger adds a highlighted pending row instantly; the row stays highlighted until you edit it. Generic sources (folder watch, UDP, serial, SCS log) live under Advanced for non-Geode setups.

The Geometrics Geode (SCS) trigger (TempCom) and its File# sync with SCS are set below; generic sources stay available under Advanced.

Advanced / generic sources
Read-only: SeisConv only watches, lists and reads this folder - it never writes into it. Latency equals the moment SCS writes the file.
Listens on 127.0.0.1 (this machine only) unless LAN is explicitly enabled. Packets are length-capped, defensively parsed and debounced.
Reads the serial trigger box's [SHOT] #id Lline:SPsp ts=… USB-serial feed at every contact closure (GPS time, no file-write latency). Plain TRIG-style lines from other hardware are accepted too.
Read-only: SeisConv tails this log and adds a row the moment SCS logs a shot - at TRIGGER time, straight from the recorder, even for shots that are never saved. FFID = the log's File #, time from the log timestamp; READ (file re-read) lines are ignored.
Fully passive & read-only: SeisConv only watches this folder - it never writes to it, opens the scratch files, or sends SCS any input. SCS rewrites its Tmp* scratch files at every trigger, so a touch = a shot; the ~6-file burst per shot is debounced to one row, and STAT.* heartbeat touches are ignored. No shot#/file - the observer fills those.
New SP = previous SP + (direction × step × interval); the first auto-row seeds SP start (SP auto-advance is unchanged). File# mode - Seed + auto-correct: shows the seeded File# instantly (counter from the seed) and corrects it from the recorder's REAL .dat File# when it lands (a mismatch is flagged); Read from file: blank until the .dat lands, then filled with SCS's exact number. Triggering ALWAYS fires on the trigger EVENT above - the .dat read is enrichment only, never a trigger. Every cell stays editable; use Renumber below… to fix a stuck / re-shot shot.
